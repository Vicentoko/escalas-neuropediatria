# Escalas de Neuropediatría

Calculadoras de uso clínico para el equipo de neurología pediátrica: perímetro craneano (OMS 2006 y CDC 2000, con edad corregida), Finnegan modificada, Sarnat modificada, M-CHAT-R, GMFCS E&R, Tardieu modificada, Ashworth modificada / MRC, SPRS, SARA, Burke-Fahn-Marsden, YGTSS, PedMIDAS y Glasgow pediátrico, ordenadas por categoría.

Es una sola página (`index.html`) sin servidor ni base de datos: todo se calcula en el dispositivo y no se guardan datos de pacientes. Funciona sin conexión una vez abierta y se puede agregar a la pantalla de inicio del celular.

Datos LMS de perímetro craneano: tablas oficiales OMS y CDC, tomadas del paquete `rcpchgrowth` (RCPCH). M-CHAT-R/F © 2009 Robins, Fein y Barton: la app solo puntúa; el cuestionario se aplica con el formulario oficial de mchatscreen.com. GMFCS E&R © CanChild 2007.
